# Evaluating large language models as grant reviewers

Code and de-identified data for:

> Williams H, Lamberg J, Lamberg E (2026). Evaluating large language models as grant reviewers: a comparative study of prompt engineering strategies. *Frontiers in Education* 11:1856134. https://doi.org/10.3389/feduc.2026.1856134

The study compared reviews generated by three commercial LLMs (OpenAI GPT-5 Nano, Google Gemini 2.5 Flash, xAI Grok 4 Fast Reasoning) with reviews from four human experts on three de-identified faculty seed-grant applications, under three prompt-engineering conditions (zero-shot, few-shot, few-shot + strict scoring instructions).

## What is here

```
  llm_criterion_rationales.csv  486 criterion-level written rationales produced by the LLMs (names removed)

  strict_scoring_v1.md      Experiment 3 prompt (few-shot + strict)    = Supplementary Appendix B.3

```

## Reproducing the published results

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python analysis/reproduce_results.py     # ~1 min (10,000-resample bootstrap)
python analysis/make_figures.py
```

`analysis/output/tables.md` reproduces Table 2, Table 3, the criterion-level tests with Holm correction, the recommendation distributions, the application-level means plotted in Figure 2, the within-application dispersion figures, the mixed-effects estimates, the sensitivity kappas and the exploratory ANOVA. Point estimates, t-test p-values, Cohen's κ, Holm-corrected p-values, vendor means, mixed-model estimates and the ANOVA reproduce the article exactly. Bootstrap confidence intervals are Monte Carlo quantities and reproduce the published intervals to within about ±0.1 points (mean difference) or ±0.02 (Glass's Δ); the seed is set in `reproduce_results.py`.

## Data notes

* Applications are coded FC1, FC2, FC3 and human reviewers R1–R4, as in the article. FC3 served as the few-shot training example and is therefore absent from the Experiment 2–3 comparisons.
* The application documents themselves (cover pages, project narratives, biosketches, budgets) are **not** distributed. They identify the applicants and co-investigators, and the consent obtained covers use of the review scores, not public release of the proposals. The pipeline expects them under `llm/scenarios/<applicant>/` as `coverpage.md`, `project.md`, `biosketches.md`, `budget.md`; that directory is git-ignored.
* Written LLM rationales are included verbatim except that personal names have been replaced with `[name removed]`.
* One criterion-level value (Team Strength, one review of FC2 in Experiment 3) is missing in the source output; the total score for that review was produced by the model and is retained. This matches the article's Methods.
* Ethics: reviewed by the Stony Brook University IRB (Protocol IRB2025-00534), classified as non-human-subjects research.

## Review-generation pipeline

`scripts/grant_review_processor.py` reads each application folder, converts the documents to Markdown (`scripts/markdown_conversion.py`), assembles the prompt from `llm/prompts/config.json`, calls each vendor through `scripts/connectors/`, and stores the JSON-formatted review in a SQLite database and an `outputs/` folder. All October 2025 runs used the model identifiers in `data/llm_reviews.csv`; xAI Grok used temperature 0.1 and max_tokens 4000, OpenAI and Google models used vendor defaults (see article Section 2.4 for the resulting limitation). The pipeline also contains an Anthropic connector that is not part of the study.

Example: `python scripts/grant_review_processor.py --model all --iterations 3 --experiment baseline_v1`

## Development history

Before the design reported in the article was fixed, the same pipeline was exercised in pilot runs with additional models (GPT-4.1 mini, GPT-5 mini, Claude 3 Opus) and with an earlier single-example prompt variant. Those pilot outputs were used only to debug the pipeline and to settle on the final prompt set and vendor list; they do not enter any analysis, table or figure in the article and are not included in this repository. A fourth application submitted in the same funding cycle was excluded at the outset because the applicant declined consent; no data from it are used or distributed.
